What is in the portal

  • 16 screen states across overview, subcontractors, companies and subscriptions.
  • 8 user stories (3 Must, 5 Should), 4 blocked on back-end capabilities.
  • 4 use cases (UC-01 to UC-04) with 2 failure paths (F-01, F-02).

Read in this order

  1. Quick Start for the one-minute view.
  2. User Stories for what the portal is for and what is blocked.
  3. Use Cases for the step-by-step journeys.
  4. Screen Specification for the per-screen detail.
  5. Usage Guide when you are using the portal.

Open questions

The eight open questions (OQ-1 to OQ-8) are the faked capabilities the portal depends on: admin auth, the activity-feed event bus, suspend, plan changes, usage reset, invites and verification, plan persistence and invoices. They live in User Stories.
