# Oversee a subbie
1. Open the Subcontractors list (H02) and filter by status (E08).
2. Open a subbie (H03) to read the live activity feed, which reflects the deal stage (E01 to E07).
[[shots: H02, H03]]

# Support a company
1. Open a company from the Companies list (H04, H05).
2. On the Company Profile (H06), review plan and usage, then act: suspend, change plan, move to free, grant or reset limits, resend invites, verify, or view invoices.
[[shots: H06]]

# Run a plan
Create or edit a plan's price, limits and features on Edit Subscription (H08), reached from the Subscriptions list (H07).
[[shots: H07, H08]]

# If something looks off
- Totals, usage meters and per-subbie stats are sample data.
- Admin actions and the live feed are not live in this prototype. See the {{doc:guide|Usage Guide}}.
