# Tenderfy: every flow

Subbie = subcontractor.

Contractor = head contractor.

Admin = Tenderfy team.

&nbsp;

Edge = a normal but less common state. Error = something went wrong. Only the ones that exist in the prototype are listed.

&nbsp;

---

## 1. The main flow

One quote, start to finish.

&nbsp;

### 1.1 Overall

&nbsp;

1. Contractor sends a request.

2. Subbie gets it. Status: Invited.

3. Subbie opens it.

4. Subbie replies: will respond, ask for info, or decline.

5. Subbie prices it and submits. Status: Quote submitted.

6. Contractor compares the quotes.

7. Contractor picks one. That subbie is Awarded. The rest are Not awarded.

8. Subbie sees the win. A quote-accepted email links them back in.

9. Admin sees the whole thing on the subbie's feed.

&nbsp;

A subbie can withdraw before award. Status: Withdrawn.

&nbsp;

Along the way, either side can message on the request. The subbie can ask the contractor a question. The contractor can message the subbie. The other side is alerted.

&nbsp;

### 1.2 From the subbie's side

&nbsp;

1. A request lands. Status: Invited.

2. Open it. Read the task, due date, and documents.

3. Reply: say you will respond, ask for info, or decline.

4. Price it as line items and submit. Status: Quote submitted.

5. Wait for the contractor to decide.

6. You win (Awarded) or you do not (Not awarded). An email links you to the win.

7. Track the work on Awarded Work.

&nbsp;

You can withdraw your quote any time before the contractor awards.

&nbsp;

### 1.3 From the contractor's side

&nbsp;

1. Create a request and send it to the subbies you want.

2. Watch who responds: will respond, asked for info, submitted, or declined.

3. Nudge anyone still quiet.

4. Compare the quotes that come in.

5. Pick one. That subbie is awarded. The rest are marked not awarded.

6. The awarded subbie is notified.

&nbsp;

### 1.4 From the admin's side

&nbsp;

1. The request shows up on the subbie's activity feed. Status: Invited.

2. Each step lands on the feed: responding, info requested, submitted.

3. The award shows up (or the decline, or the withdrawal).

4. Check any company's plan, usage, or status at any point.

&nbsp;

### 1.5 Subbie journey: sign up to finishing a contractor quote

&nbsp;

1. Open the landing and create an account.

2. Verify your email.

3. Land on the dashboard.

4. Open the request under Action needed.

5. Read the task, due date, and documents.

6. Start a quote.

7. Add line items. GST is added.

8. Add inclusions, exclusions, and assumptions.

9. Review the summary.

10. Send. The request moves to Quote submitted.

11. Update or withdraw before the contractor decides, if you need to.

12. If you win, see it on Awarded Work. Status: Awarded.

&nbsp;

Where it can break: email verification can fail or expire (see 2.1). A missing quote field is flagged before you can send (see 2.2).

&nbsp;

### 1.6 Subbie journey: sign up to creating an external quote

&nbsp;

1. Open the landing and create an account.

2. Verify your email.

3. Land on the dashboard.

4. Fill in your profile and add files, if you want.

5. Open New Quote.

6. Add line items. GST is added.

7. Add inclusions and exclusions.

8. Review and send.

9. Send it to your client: download the PDF, copy a secure link, or email it.

10. Open it later as an external quote, resend it, or update its status.

&nbsp;

Where it can break: email verification can fail or expire (see 2.1). A missing quote field is flagged before you can send (see 2.2).

&nbsp;

## 2. Subbie

&nbsp;

### 2.1 Sign in

Open the landing → log in (or reset a forgotten password), or create an account → verify email → dashboard.

&nbsp;

Edge: a brand-new account lands on an empty dashboard (counts show 00).

Edge: after sign-up you wait on the verify-email screen until the link is used.

Error: bad or incomplete sign-up details are flagged.

Error: a broken or expired verification link shows an error and offers a new link.

&nbsp;

### 2.2 Quote a request

Open the request (read the details, due date, the contractor's documents (a full file or a snippet of selected pages) and their notes) → add line items (GST is added) → add inclusions, exclusions and assumptions (type a chip, press Enter; inclusions are removable chips, exclusions toggle on and off) → attach your own documents if needed → review → send.

&nbsp;

Error: a missing required field is flagged inline, and you cannot send until it is fixed.

&nbsp;

### 2.3 Reply fast

Open the request → will respond, ask for info, or decline.

&nbsp;

Edge: declining ends the request for you; the contractor can move on.

&nbsp;

### 2.4 Change a quote

Open the sent quote → update it, or withdraw it.

&nbsp;

A message confirms Quote updated or Quote withdrawn.

&nbsp;

### 2.5 Awarded work

Open Awarded Work → see the wins and contract value.

&nbsp;

### 2.6 Open work from the email

A quote-accepted email links you straight back to the win.

&nbsp;

### 2.7 Profile and files

Fill in the profile. Add files under All Files. Open a file to view it.

&nbsp;

Edge: an empty profile prompts you to complete it.

Edge: an empty files area explains how to add files.

&nbsp;

### 2.8 Notifications

Open Notifications → see request activity.

&nbsp;

### 2.9 Account settings

Open Settings → set your account preferences.

&nbsp;

### 2.10 Quote Settings (Quote Template Management)

Open Quote Settings → manage your quote templates. Edit the template freely: the cover sheet, sections, wording and the defaults new quotes start from (GST, terms, validity). Save, and reuse the template across quotes.

&nbsp;

### 2.11 Capability Statement (Ray)

Open Capability Statement → Ray drafts it.

&nbsp;

Free: you can build and preview it, with 2 Ray revisions. The gate is at the output, not the build: to edit, customise, download or keep revising, upgrade.

Premium: full edit and customise, download, and unlimited Ray revisions. After the first build it opens in a manager view.

&nbsp;

### 2.12 Company Documents (Premium)

Ray extracts a branded template from your documents. From there you can:

&nbsp;

- Let Ray build from or edit the template with a prompt, drawing on a website, a chat, or a file.

- Or edit it directly with the Block Builder.

&nbsp;

Document types: cover letter, prequal pack, one-pager. Gated at the output, like the capability statement.

&nbsp;

### 2.13 Project Library (Premium)

Open Project Library → build a project profile with the Block Builder (the same block builder used in Business Admin) → save it to your library → open one to view it.

&nbsp;

Attach profiles to quotes or share them with contractors. Over time they also help Ray respond to future requests.

&nbsp;

Edge: on the free plan the library is locked and prompts an upgrade.

&nbsp;

### 2.14 Upgrade

Hit a locked feature → open Premium → pick a plan.

&nbsp;

### 2.15 External quote

Open New Quote → price it → send to your client: download the PDF, copy a secure link, or email it.

&nbsp;

Error: same as a request quote, a missing required field is flagged before you can send.

&nbsp;

### 2.16 Message the contractor

Open a request → send a message to ask a question → the contractor is alerted. Messages collect in the Messages area.

&nbsp;

Free can upload only. Premium unlocks Ray.

&nbsp;

## 3. Contractor

&nbsp;

### 3.1 Home

Open Subcontractors → see the directory, the summary tiles, and the open requests. Search the roster to find a subbie.

&nbsp;

### 3.2 Add subbies

Add one (company, email, ABN, trades; only company and email are required), or import a CSV: download the template → upload the file → map your columns → fix any flagged rows → import and invite. Invites go out staggered to clear spam filters.

&nbsp;

Error: a bad email shows "Enter a valid email address".

Error: a bad ABN shows "That ABN is not valid - check the number". ABN is optional.

Error: a CSV import flags any bad rows.

&nbsp;

### 3.3 View a subbie

Open a subbie → check their capability, compliance, and request history.

&nbsp;

### 3.4 Prepare a tender and send a request

&nbsp;

1. Open the tender. Keep notes on it (for example chase reminders).

2. Build the pack: pages, attachments, preview.

3. Create a quote request: set the task and the due date.

4. Attach documents, and choose per file how each one is sent: in full, or as a snippet of only the selected pages, so the subbie receives just those pages. A page-jump helps you navigate a large file. Pull from this tender or your File Manager, and Ray can suggest the pages that matter.

5. Pick recipients. Subbies not yet on Tenderfy get an invite to view it without an account.

6. Send. You are notified as quotes come in.

&nbsp;

### 3.5 Chase

Pick a subbie → open the request → nudge. A nudge can carry a short message, capped at 2 per subbie. Auto-nudge runs on the delay you set, and each row shows how many nudges have been sent.

&nbsp;

Error: nudging a subbie already at the cap shows "Nudge limit reached".

&nbsp;

### 3.6 Award

Open Compare Quotes → pick one → that subbie is awarded.

&nbsp;

### 3.7 Track

Open a request → see Will respond, Quote submitted, Awarded, Unsuccessful, or Declined.

&nbsp;

### 3.8 Settings

Set the sender (From, Reply-To, display name), the greeting and the intro and nudge messages (with [Task title], [Due date] and [First name] placeholders), the nudge delay, the max nudges per request, and the send window. Send a test email to check it.

&nbsp;

### 3.9 Message a subbie

On a request → send a message to the subbie. They are alerted.

&nbsp;

## 4. Admin

&nbsp;

### 4.1 Subbies

Open the list → filter by status → open one → read the live feed (invited, responding, info requested, submitted, awarded, declined, or withdrawn).

&nbsp;

Edge: bulk actions appear only once you select at least one row.

&nbsp;

### 4.2 Companies

Open a company → see its summary and subbies → open the account profile → see plan and usage → suspend, change plan, reset limits, resend invites, verify, or view invoices.

&nbsp;

### 4.3 Subscriptions

Open a plan → set price, limits, and features.

&nbsp;

Edge: deleting a plan that companies are on asks you to confirm first.

&nbsp;

### 4.4 Overview

Open the dashboard → see the platform figures.
