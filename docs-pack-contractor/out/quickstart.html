The main task: request and award

  1. Add or import subbies from the Subcontractors home (H01, E06).
  2. Create a New Quote Request (H05): task, due date, documents, recipients. Add inclusions and exclusions with Enter.
  3. Chase anyone awaiting with a nudge (E08).
  4. Compare the quotes side by side (H06) and accept one to award.
